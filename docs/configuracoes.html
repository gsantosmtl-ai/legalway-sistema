💾 Backup do sistema

Baixa tudo: os dados de todos os módulos, os documentos anexados, usuários e chat. Guarde em um lugar seguro — pelo menos uma vez por semana. Restaurar: documentos, usuários e mensagens do arquivo são acrescentados, sem apagar nada. Já os módulos (leads, funil, contratos, financeiro…) são substituídos inteiros pelo que vier no arquivo — um arquivo com 2 leads deixa o módulo com 2 leads. O sistema confere e avisa antes.

Cópias automáticas

O sistema guarda uma cópia por dia no servidor (as 14 últimas). Baixe uma delas quando precisar — e mesmo assim, guarde um backup fora do sistema de vez em quando.

↩️ Recuperar algo apagado

Apagou uma ficha sem querer? Cada gravação vira uma versão, e as 30 últimas de cada módulo ficam guardadas. Aqui aparece o que existia nelas e não existe mais hoje — você devolve um registro só, sem mexer em nada que foi feito depois. (Restaurar o backup inteiro faz o contrário: troca o módulo todo.)
